# Clipline UI 优化方案

## 1. 结论

不采用完整 Neumorphism 方案。Clipline 是录像回放、检索、导出和源管理工具，界面需要像 UniFi Protect 一样偏工作台、偏高密度、偏可扫描，而不是柔软装饰感很强的展示型界面。

推荐方向：

```text
UniFi-inspired Soft Utility UI
```

关键词：

- 录像内容优先。
- 信息密度高，但边界清晰。
- 浅灰背景、白色工作区、轻边框、蓝色操作态。
- 图标使用 lucide，不使用 emoji。
- 日志不出现在普通用户界面，只保留后端诊断能力。
- 搜索、字幕、片段墙都服务于回看和检索，不拆成太多孤立入口。

## 2. 当前问题

### 2.1 信息架构偏散

当前主导航包含：

- 录像回放
- 片段墙
- 字幕
- 录像源
- 导出任务
- 日志
- 设置

问题：

- `片段墙` 本质是回看页的一种浏览方式，不需要独立成一级模块。
- `字幕` 更像智能检索/语音识别能力的一部分，不适合作为孤立入口。
- `日志` 与之前确定的“界面不要显示日志”冲突。
- 一级入口过多，用户进入后不知道主流程是“选源 -> 找时间 -> 播放/导出”。

### 2.2 顶部搜索常驻抢视觉重心

当前全局搜索框常驻在 `stageTop` 右侧。对 NVR/录像回看产品来说，用户的主心智是视频画面、时间线和片段，搜索应是快捷能力，而不是长期占用顶部空间。

### 2.3 视觉语言还不够统一

当前已经有 UniFi 风格基础，但还存在几个不一致点：

- 部分交互使用 emoji 表达状态或操作。
- 设置、源管理、搜索、片段卡片的控件密度和层级不完全一致。
- 有些面板偏卡片化，容易稀释视频工作台的专业感。
- 状态、按钮、输入框、表格还需要统一 token。

### 2.4 日志入口需要移出普通 UI

日志系统可以保留，也应该继续完善，但普通用户界面不应该出现“日志”模块。日志更适合：

- 后端文件。
- API 诊断接口。
- 管理员隐藏入口。
- 开发环境专用开关。

## 3. 目标信息架构

主导航建议收敛为 5 个入口：

```text
回看
智能检索
录像源
导出
设置
```

### 3.1 回看

默认首页。负责最高频流程：

- 选择录像源。
- 选择日期或时间范围。
- 查看时间线。
- 播放片段。
- 浏览片段缩略图。
- 选择区间并导出。

`片段墙` 合并到回看页，作为播放器下方或侧边的浏览模式。

### 3.2 智能检索

承载所有“找内容”的能力：

- 文本搜索。
- 语音识别结果搜索。
- 字幕/转写任务入口。
- 结果定位回放。

`字幕` 不再作为一级导航，归入智能检索或设置中的 ASR 配置。

### 3.3 录像源

负责源的生命周期：

- 新建源。
- 选择目录。
- 编辑名称和路径。
- 启用/停用。
- 手动重新扫描。
- 查看最近扫描状态。

页面应偏表格和抽屉，不做大面积装饰卡片。

### 3.4 导出

负责导出任务和导出历史：

- 进行中任务。
- 已完成任务。
- 失败任务。
- 下载/重试/删除。

导出入口同时保留在回看页的区间选择工具里。

### 3.5 设置

只放低频配置：

- 系统概览。
- 录像配置。
- 导出配置。
- 语音识别配置。
- 关于。

不显示普通日志入口。

## 4. 页面布局方案

### 4.1 全局外壳

```text
+------+------------------------------------------------+
| 左栏 | 顶部状态区                                      |
|      +------------------------------------------------+
|      | 主工作区                                        |
|      |                                                |
|      | 回看/检索/源管理/导出/设置                       |
+------+------------------------------------------------+
```

左侧窄导航：

- 宽度 56-64px。
- 只放图标，hover/tooltip 展示名称。
- 选中态使用浅蓝底和蓝色图标。
- 底部只保留设置入口。
- 不展示日志入口。

顶部状态区：

- 左侧展示当前页面标题和关键 meta。
- 右侧展示刷新、源选择、搜索按钮。
- 搜索用按钮或命令面板触发，保留 `Ctrl/Cmd + K`。

### 4.2 回看工作台

目标布局：

```text
+------------------------------------------------------+
| 标题/源/日期/刷新/搜索                                |
+------------------+-----------------------------------+
| 时间/源控制区     | 主播放器                           |
| - 源              |                                   |
| - 日期            |                                   |
| - 当前扫描状态    |                                   |
| - 快速操作        |                                   |
+------------------+-----------------------------------+
| 片段缩略图条 / 片段墙 / 导出区间                       |
+------------------------------------------------------+
```

重点：

- 视频播放器是第一视觉重心。
- 片段缩略图使用真实缩略图或视频帧，不用纯图标占位作为常态。
- 时间线靠近播放器，导出区间选择要和时间线建立明显关系。
- 左侧控制区只放回看必需项，不放日志和系统说明。
- 片段卡片固定比例，避免 hover 或状态文字导致布局跳动。

### 4.3 片段卡片规范

每张片段卡片建议结构：

```text
+-----------------------------+
| 缩略图                       |
| [源名称]                     |
|                 [可播放/转码]|
| 2026-05-24 10:49            |
+-----------------------------+
```

规则：

- 16:9 或接近监控画面的固定比例。
- 左上角显示源名称。
- 左下角显示时间。
- 右下角显示状态。
- 选中态用蓝色描边或浅蓝内阴影。
- 右键菜单全部使用 lucide 图标，不使用 emoji。
- 识别状态用小 badge 表达：未识别、等待中、识别中、已识别、失败。

### 4.4 智能检索页

布局：

```text
+------------------------------------------------------+
| 搜索输入 / 源筛选 / 时间范围                          |
+--------------------------+---------------------------+
| 搜索结果列表              | 结果预览和片段定位          |
+--------------------------+---------------------------+
```

原则：

- 搜索结果按时间倒序。
- 每条结果显示源、时间、命中文本、识别状态。
- 点击结果直接跳回回看页并定位片段。
- 搜索历史可以收起，不常驻挤占空间。

### 4.5 录像源页

布局：

```text
+------------------------------------------------------+
| 新建源 / 扫描全部 / 刷新                              |
+------------------------------------------------------+
| 源表格                                                |
| 名称 | 路径 | 状态 | 最近扫描 | 片段数 | 错误数 | 操作 |
+------------------------------------------------------+
```

新建/编辑使用右侧抽屉：

- 源名称。
- 视频目录。
- 目录选择器。
- 保存并扫描。

减少大卡片，用表格提高管理效率。

## 5. 视觉规范

### 5.1 色彩

```text
页面背景     #f4f6f8
主表面       #ffffff
弱表面       #f8fafc
边框         #e4e8ed
强文本       #132033
正文文本     #334155
弱文本       #697586
主操作蓝     #2f6df6
成功绿       #29a36a
警告橙       #d9852b
危险红       #d64545
视频底色     #050608
```

要求：

- 不做单一蓝色铺满。
- 不使用大面积紫蓝渐变。
- 不使用装饰 orb、bokeh、无意义背景图。
- 视频区域用深色承载，其他工作区保持浅色。

### 5.2 圆角和阴影

```text
小控件圆角   8px
面板圆角     10px
播放器圆角   8px
卡片圆角     8px
阴影         轻量，主要依靠边框建立层级
```

避免：

- 32px 以上的大圆角。
- 强烈 Neumorphism 外凸/内凹效果。
- 卡片套卡片。

### 5.3 字体和密度

- 字体使用 Inter 或系统 sans-serif。
- 页面标题 18-22px。
- 面板标题 13-15px。
- 表格和卡片 meta 12-13px。
- 工作台优先紧凑，不做营销页式大标题。

### 5.4 图标

- 统一使用 lucide-react。
- 按钮图标 16-20px。
- 不使用 emoji 作为功能图标。
- 不用手写 SVG 替代已有 lucide 图标。

## 6. 开发阶段

遵循“先后端后前端”的模式，但本轮 UI 优化大部分是前端重构。后端只做必要的接口确认和补齐。

### P0 后端和接口确认

- 确认回看页需要的源、时间线、片段、扫描任务、导出任务接口稳定。
- 确认普通 UI 不再调用日志展示接口。
- 确认缩略图字段 `thumbnailUrl` 的返回策略。
- 若缩略图还不稳定，前端保留视频帧占位，但视觉上仍按缩略图卡片处理。

验收：

- 回看、源管理、导出、搜索所需接口都能在 Docker 环境返回。
- 普通 UI 没有日志入口和日志请求。

### P1 信息架构清理

- 主导航改为：回看、智能检索、录像源、导出、设置。
- 移除普通 UI 的日志入口。
- `片段墙` 合并到回看页。
- `字幕` 合并到智能检索或设置 ASR。
- 全局搜索改为按钮/命令面板触发。

验收：

- 左侧导航不超过 5 个主要入口。
- 页面内看不到“日志”模块。
- `Ctrl/Cmd + K` 仍可搜索。

### P2 回看工作台重做

- 播放器区域放大，成为第一视觉中心。
- 源、日期、扫描状态、刷新动作集中到控制区。
- 片段墙固定在播放器下方，支持密集缩略图浏览。
- 时间线和导出区间选择做成强关联。
- 优化空状态：无源、无片段、扫描中、扫描失败。

验收：

- 用户第一眼能看到当前源、当前时间范围和播放器。
- 选择片段后，播放器、时间线、片段卡片状态同步。
- 片段列表不会因为状态变化产生明显布局跳动。

### P3 智能检索体验整理

- 搜索入口从顶部常驻输入框改为搜索按钮和快捷键。
- 搜索页提供源筛选、时间筛选、结果列表、预览定位。
- 字幕/转写状态整合为结果辅助信息，不独立抢入口。

验收：

- 搜索结果可以一键定位回看。
- 搜索空状态、加载状态、错误状态完整。
- 搜索历史可以清除，但不干扰主工作台。

### P4 源管理和设置页收敛

- 录像源页改为表格加抽屉。
- 新建源流程突出“名称 + 目录”两个核心字段。
- 设置页只保留低频配置，不放普通日志查看。
- 系统状态作为设置概览，不抢主流程。

验收：

- 新建源流程在 3 步内完成：新建、选择目录、保存并扫描。
- 源的启用/停用、扫描、编辑都有清晰反馈。
- 设置页没有日志 tab。

### P5 视觉 token 和组件整理

- 在 CSS 中集中定义颜色、圆角、阴影、间距 token。
- 统一按钮、输入框、select、badge、表格、空状态。
- 替换 emoji 图标为 lucide 图标。
- 补齐 hover、focus、disabled、loading 状态。

验收：

- `rg` 检查普通 UI 不再使用 emoji 图标。
- 所有可点击元素有 hover/focus 反馈。
- 375、768、1024、1440px 下无明显重叠和横向溢出。

## 7. 不做范围

本轮不做：

- 完整 Neumorphism 视觉系统。
- 营销型 landing page。
- 大面积暗黑模式重构。
- 移动端完整 NVR 操作体验。
- 在普通用户界面展示日志。
- 为了 UI 改动大规模重写后端。

## 8. 建议实施顺序

```text
P0 接口确认
P1 信息架构清理
P2 回看工作台
P3 智能检索
P4 源管理/设置
P5 视觉 token 和 QA
```

建议先做 P1 + P2，因为它们最直接解决“界面太丑、入口混乱、像不像 UniFi”的问题。
