# Clipline Full Redesign 开发任务清单

状态：收尾中（M7 视觉、核心交互与发布验证已完成；剩余 M0/M1 代码组织清理）

设计基准：`frontend/prototypes/clipline-full-redesign`
配套规范：`docs/FULL_REDESIGN_ALIGNMENT.md`

## 1. 执行规则

- 必须按任务依赖顺序执行；不得在应用骨架完成前并行保留旧、新两套导航。
- 原型是布局、组件结构、密度、间距、颜色、字体、图标、文案和交互的唯一基准。
- 当前 `frontend/src` 只提供真实业务逻辑和 API 接入，不作为视觉依据。
- 每个页面必须先接通真实数据，再补加载、空、错误、禁用和长文本状态。
- 每个页面完成后立即做同 viewport、同数据状态截图对比，不把视觉回归集中到最后。
- 除修复响应式、可访问性或浏览器故障外，不得自行改变原型。
- 任务状态使用：`[ ]` 未开始、`[-]` 进行中、`[x]` 已完成、`[!]` 阻塞。
