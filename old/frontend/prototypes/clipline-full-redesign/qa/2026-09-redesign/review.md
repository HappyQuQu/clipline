# Clipline 原型重设计 · 2026-09-08

用户要求重新设计现有原型。范围是四个现有一级页面：回看、片段库、任务、管理；保持 NAS 录像文件工作台的产品边界。

## 旧版观察

当前轮次从本地启动并截图现有 full-redesign 原型，截图见 `before-review.png`。

- 回看侧栏长期展示目录路径、扫描元数据，挤占播放器。
- 画面使用 cover 裁切，观看时不能看到完整录像内容。
- 导出入口重复，默认选择区间，浏览和截取缺少明确状态切换。
- 日期、上一/下一片段、字幕搜索、部分筛选和模型按钮只有外观，没有连贯交互。
- 旧导出弹窗声称“保留时间断档”，与业务规则不符。

## 新版设计

- 全局使用浅灰画布、白色内容面板、墨色文字与克制蓝色操作。清晰文字导航替代分散图标；保留四个一级入口。
- 回看顶部只放录像源和日期。播放器保留完整画幅，播放、时间轴、当天片段形成连续查看路径。
- 字幕/详情栏可以收起；点击字幕或时间轴定位同步更新画面、时间、选中片段。
- 截取是显式模式，支持调整起止时间，导出确认展示实际录像长度、缺失/未选区间与导出方式。
- 片段库分离“查看详情”与“批量选择”，支持时间、源、日期、标签、识别状态过滤及列表/网格。
- 任务用可读标题和时间范围呈现，显示进度、重试、完成结果；新建导出/识别进入同一任务列表。
- 管理重新整理目录配置、活动日志和设置；主要表单、筛选、保存、模拟处理操作可体验。

## 实现与边界

入口为 `src/Workspace.jsx`；基础样式为 `src/workspace.css`，片段库/任务及管理各有独立样式。旧页面代码仅供管理组件复用和历史参考。

录像画面使用仓库已有真实静态帧；播放、识别、扫描、导出进度均为演示，不连接后端、不访问录像目录、不生成真实导出视频。示例字幕和日志允许本地文件下载。管理配置只保存在原型浏览器的本地存储。

## 验证记录

- 使用 Codex 内置浏览器检查桌面与 390px 手机视口。
- 修正图片因网格固有尺寸溢出造成的裁切；图片盒与播放器高度一致，object-fit 为 contain。
- 片段库关键词过滤返回匹配片段，日志类型过滤返回对应事件。
- 页面切换重置滚动位置；搜索对话框聚焦输入框并支持 Escape/焦点循环。
- 回看字幕点击后显示对应的 09:38:28；搜索结果点击后定位到 09:35:54；时间轴点击片段中部定位到 09:32:58，而非片段起点。
- 截取时间改为保留编辑草稿的文本输入，失焦或 Enter 校验提交，避免原生时间输入回弹。09:24:00–09:36:00 正确计算为 4 个片段、实际 11:59、断档 00:01。
- 非连续选择 09:08 与 09:35 两个片段时，导出正确显示实际 11:06，区分 00:02 无录像断档与 21:34 未选录像。
- 自定义「工作室-打印过程」精准导出进入任务列表，模拟进度完成。09:30 语音识别完成后生成 2 条明确示例字幕，点击定位成功；视觉失败任务重试完成后打开 2 个示例标签，没有误生成语音字幕。
- 空日期状态、四个一级页面在 390px 视口均无页面横向溢出；当前浏览器错误和警告记录为空。
- 收紧辅助文字与彩色状态标签对比度，保留视觉层级；主要浅色表面上的常用次要文字色达到约 4.6:1 以上。
- `npm run build`、`npm run test:sites`（4/4）、`git diff --check` 通过。没有部署或覆盖正式 Docker 应用。

截图保存在本目录：`review-desktop.png`、`review-mobile.png`、`library-desktop.png`、`tasks-desktop.png`、`manage-desktop.png`、`export-desktop.png`。
