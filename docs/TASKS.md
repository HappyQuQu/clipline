## 2. 本地测试约定

| 项目 | 固定约定 |
| --- | --- |
| 用户指定映射目录 | `/path/to/recordings`（替换为实际宿主机目录） |
| 容器录像根 | `/recordings`，映射上述目录并设置只读 |
| 真实录像源 | 在目录浏览中选择 `/recordings/media` 下的实际录像目录 |
| 新测试数据 | 宿主机仓库下的 `data/local-test` → 容器 `/app/data`，可写 |
| 旧数据库与缓存 | 映射目录中的旧 DB、设置、models、exports 等不导入、不覆盖，不作为录像源 |
| 合成测试样本 | 放独立临时测试目录或临时卷，用于损坏/跨日/重叠等案例；不写入真实录像目录 |
| 验证边界 | 原目录只读，执行前后核对测试原文件校验值；实际 Docker 可访问性由 D1-08 验证 |

数据库、导出、代理、日志和临时文件不得写到用户指定的映射目录。`data/` 已被仓库忽略；不提交录像、数据库或测试输出。
