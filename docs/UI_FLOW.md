# Clipline UI Flow

> 当前 UI 以 `frontend/prototypes/clipline-full-redesign` 为唯一视觉与交互基准。完整页面规格、token、差异清单与验收方法见 `docs/FULL_REDESIGN_ALIGNMENT.md`。本文中的旧描述若与该基准冲突，以 full redesign 为准。

## 1. 文档目的

本文档定义 Clipline MVP 的页面结构、核心交互流程、空状态和错误状态，供产品、设计、前端、后端联调使用。

产品以桌面端体验为主，同时按照原型的 1180、900、660 三档断点保证窄屏可用。

## 2. 信息架构

一级导航包含四个入口：

```text
回看
片段库
任务
管理
```

全局导航：

- 顶栏承载 Logo、全局字幕搜索、通知和账户。
- 左侧窄导航栏只承载回看、片段库、任务、管理。
- 全局搜索以下拉浮层显示结果，不作为独立页面。
- 回看页左侧上下文栏提供当前源、日期、显示范围和扫描操作。
- 管理页二级导航包含录像源、活动日志、设置。
- 设置页三级分类包含概览、扫描与索引、导出、识别与任务、模型管理、日志与诊断、关于。

## 3. 回看页

回看页是用户进入应用后的主页面。

### 3.1 页面目标

- 按源和日期查看录像片段。
- 通过时间线快速定位真实时间。
- 播放当前片段。
- 连续播放后续片段。
- 选择时间范围并导出。

### 3.2 页面布局

```text
+------+----------------+----------------------------------------+
| 导航 | 控制栏          | 主工作区                                |
|      | - 源选择        | - 大尺寸视频播放器                      |
|      | - 日期          | - 左侧时间轨                            |
|      | - 新建源        | - 悬浮播放/导出/扫描工具                |
|      | - 当前源状态    | - 导出区间                              |
|      | - 最近扫描      | - 录像片段卡片墙                        |
+------+----------------+----------------------------------------+
```

视觉严格使用 full redesign：Apple-like 浅色表面、细边框、紧凑间距、`#1677ff` 蓝色操作态、视频内容优先。

### 3.3 首次进入

如果还没有任何源：

- 显示无源空状态。
- 主操作按钮为“新建源”。
- 点击后进入设置页的新建源弹窗或抽屉。

文案：

```text
还没有配置录像源
请先新建一个源，并选择容器内的视频目录。
```

### 3.4 已有源但当天无视频

条件：

- 已选择源。
- 已选择日期。
- 当天没有扫描到视频片段。

展示：

- 播放器区域显示空状态。
- 时间线显示完整空白区间。
- 片段列表为空。

文案：

```text
这一天没有找到录像片段
```

操作：

- 切换日期。
- 切换源。
- 手动重新扫描。

## 4. 片段库

片段库用于筛选、比较、选择和批量处理已索引片段。

### 4.1 页面结构

- 页头：标题、批量识别、导出所选。
- 筛选栏：关键词、录像源、识别状态、日期、网格/列表切换。
- 内容区：桌面端三列网格或列表。
- 右侧详情：片段预览、来源、日期、时长、状态、标签与操作。
- 底部批量条：选择数量、取消、视觉识别、合并导出。

### 4.2 选择与处理

- 单击卡片选中片段并同步更新右侧详情。
- 选中态使用蓝色描边和左上角选择标记。
- 详情区可创建语音识别、视觉识别或当前片段导出任务。
- 多选时显示固定批量操作条。

## 5. 任务页

任务页集中展示导出、语音识别和视觉识别任务。

### 5.1 页面结构

- 状态筛选：全部、进行中、待处理、已完成、失败。
- 表格字段：任务、类型、来源、状态、结果/进度、更多操作。
- 已完成导出提供浏览器下载。
- 页面底部展示处理中、识别完成和需要处理摘要。

### 5.2 状态展示

- `queued` 映射为“待处理”。
- `running`、`processing` 映射为“进行中”。
- `completed` 映射为“已完成”。
- `failed` 映射为“失败”，并显示可理解原因。

## 6. 管理页

管理页统一承载录像源、活动日志和设置。

### 6.1 录像源

- 展示录像源、目录路径、状态、片段/错误和最后扫描。
- 选中源后展示最近片段预览和配置详情。
- 单源配置包含扫描方式以及语音/视觉识别覆盖项。

### 6.2 活动日志

- 展示扫描、导出、识别和文件失败事件。
- 支持关键词、类型、录像源、日期筛选。
- 使用紧凑表格，不使用独立一级导航或大型统计仪表盘。

### 6.3 设置

- 概览。
- 扫描与索引。
- 导出。
- 识别与任务。
- 模型管理。
- 日志与诊断。
- 关于。

- 全局设置与录像源覆盖项必须明确区分。
- 导出目录只展示只读服务端暂存路径，用户下载位置由浏览器决定。

## 7. 新建源流程

### 7.1 入口

用户可以从两个地方新建源：

- 回看页无源空状态。
- 管理 / 录像源。

### 7.2 表单字段

必填：

- 源名称。
- 视频目录。

系统自动处理：

- 源 ID。
- 应用时区。
- 自动时间识别规则。

### 7.3 表单布局

```text
新建源

源名称
[ 门口摄像头                 ]

视频目录
[ /recordings/front-door      ] [选择目录]

目录树
/recordings
  front-door/
  dashcam/
  living-room/

[取消] [保存并扫描]
```

### 7.4 目录选择器

目录选择器只展示允许访问的录像根目录。

默认根目录：

```text
/recordings
```

目录选择规则：

- 可以展开子目录。
- 可以选择任意可读目录。
- 不展示隐藏目录。
- 不展示 `/app/data` 等应用数据目录。
- 目录不可读时置灰，并显示不可读状态。
- 支持手动输入容器内路径，作为高级兜底方式。

### 7.5 保存校验

保存前校验：

- 源名称不能为空。
- 视频目录不能为空。
- 视频目录必须存在。
- 视频目录必须可读。
- 视频目录必须位于允许的录像根目录内。
- 视频目录不能与已有源完全相同。

保存成功：

- 创建源。
- 自动触发首次扫描。
- 返回管理 / 录像源。
- 显示扫描状态。

保存失败：

- 保留用户输入。
- 在对应字段下显示错误原因。

## 8. 源管理流程

### 8.1 源列表

每个源展示：

- 源名称。
- 视频目录。
- 启用状态。
- 最近一次扫描时间。
- 扫描状态。
- 已索引片段数。
- 错误数。

可操作：

- 编辑。
- 启用或停用。
- 重新扫描。

### 8.2 编辑源

可编辑：

- 源名称。
- 视频目录。

编辑视频目录后：

- 系统提示用户需要重新扫描。
- 保存后触发扫描。

### 8.3 停用源

停用后：

- 回看页不默认展示该源。
- 不再自动扫描该源。
- 历史索引保留。

## 9. 扫描流程

### 9.1 自动扫描

触发时机：

- 新建源成功后。
- 按配置间隔周期扫描。
- 应用启动后可触发一次扫描。

### 9.2 手动扫描

入口：

- 管理 / 录像源。
- 回看页空状态。

扫描状态：

- queued。
- running。
- completed。
- failed。

展示信息：

- 已扫描文件数。
- 已入库文件数。
- 失败文件数。
- 当前进度。
- 最近错误。

## 10. 时间线交互

### 10.1 时间线状态

时间线覆盖当天 00:00 到 24:00。

状态：

- 有录像。
- 无录像。
- 当前播放时间。
- 选中导出区间。
- 加载中。
- 片段损坏或不可播放。

### 10.2 点击时间线

用户点击有录像区域：

- 系统解析真实时间到具体片段。
- 播放器加载该片段。
- 设置片段内偏移。
- 时间线指针移动到点击时间。

用户点击无录像区域：

- 显示最近可播放时间提示。
- 提供跳转到上一段或下一段按钮。

### 10.3 拖动时间线

拖动过程中：

- 显示当前真实时间。
- P1 如果有缩略图，显示预览图。

松开后：

- 如果目标时间有录像，跳转播放。
- 如果目标时间无录像，提示最近可播放片段。

## 11. 播放流程

### 11.1 播放片段

用户点击片段：

- 播放器加载片段 stream 地址。
- 播放器跳到片段内偏移。
- 片段卡片高亮。
- 时间线指针更新。

### 11.2 连续播放

当前片段播放结束：

- 查询下一个时间顺序片段。
- 如果时间连续，自动切换播放。
- 如果存在断档，显示断档时长后切换到下一片段。
- 如果没有下一片段，停留在结束状态。

### 11.3 不可播放文件

条件：

- 浏览器不支持编码。
- 文件损坏。
- Range 请求失败。

展示文案：

```text
该片段暂时无法在线播放
可以尝试导出，或等待后续转码预览能力。
```

操作：

- 导出该时间段。
- 跳到下一片段。

## 12. 导出流程

### 12.1 进入导出模式

入口：

- 回看页“导出区间”按钮。
- 片段库详情中的“导出当前片段”。
- 片段库多选后的“合并导出”。

进入后：

- 时间线进入区间选择状态。
- 播放控制保持可用。

### 12.2 选择区间

方式：

- 在时间线上拖拽选择开始和结束时间。
- 使用时间输入框微调开始和结束时间。

展示：

- 开始时间。
- 结束时间。
- 预计时长。
- 涉及片段数。
- 是否包含断档。

如果包含断档，界面必须提示：

- 导出时会跳过断档。
- 输出文件只包含实际存在的录像内容。
- 输出视频时长可能短于选择区间。

### 12.3 选择导出模式

模式：

- 快速导出。
- 精准导出。

默认：

- 快速导出。

模式说明：

- 快速导出速度快，但裁剪点可能不完全精确。
- 精准导出更准确，兼容性更好，但 CPU 占用更高。

### 12.4 提交导出

提交后：

- 创建导出任务。
- 成功弹窗提供“查看任务”和“继续浏览”。
- 回看页可继续使用。

## 13. 任务详情

### 13.1 页面目标

- 在同一页面查看导出、语音识别和视觉识别任务状态。
- 下载已完成文件。
- 查看失败原因。
- 清理过期导出。

### 13.2 任务列表字段

- 任务名称。
- 类型。
- 来源与真实时间范围。
- 状态。
- 结果或进度。
- 更多操作。

### 13.3 任务状态

- queued：排队中。
- running：导出中。
- processing：识别处理中。
- completed：已完成。
- failed：失败。

### 13.4 任务操作

可操作：

- 下载。
- 重新导出，复用 `POST /api/exports`。P1 能力。
- 删除导出文件。P1 能力。

## 14. 空状态与错误状态

### 14.1 无源

```text
还没有配置录像源
请先新建一个源，并选择容器内的视频目录。
```

主操作：

- 新建源。

### 14.2 源目录不可读

```text
无法读取该视频目录
请检查 Docker volume 是否已正确挂载，且路径位于 /recordings 下。
```

主操作：

- 编辑源。
- 重新扫描。

### 14.3 当天无视频

```text
这一天没有找到录像片段
```

主操作：

- 切换日期。
- 重新扫描。

### 14.4 扫描失败

```text
扫描未完成
部分文件无法读取或解析，请查看扫描详情。
```

主操作：

- 查看错误。
- 重新扫描。

### 14.5 导出失败

```text
导出失败
可以尝试改用精准导出，或缩短导出时间范围。
```

主操作：

- 重新导出。
- 改用精准导出。

## 15. 响应式适配

按照 full redesign 的断点规则实现：

- 1180px 以下收窄上下文栏，片段库变为两列。
- 900px 以下回看上下文栏移到顶部，片段详情隐藏，管理侧栏收窄。
- 660px 以下一级导航移动到底部，管理导航移动到顶部横向排列。
- 片段列表、设置表单和摘要卡改为单列。
- 数据表只允许表格容器内部横向滚动。
- 导出区间与主要按钮必须保持可见，不得被裁切。
