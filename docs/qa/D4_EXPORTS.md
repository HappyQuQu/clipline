## 自动验证

Python 3.11 / 3.12 各 90 项后端测试；ruff lint/format、前端 17 项测试、生产构建和双架构镜像构建通过。新增 7 项后端导出场景覆盖：

1. 同源同日、显式选中、无录像/未选中分别计时、稳定去重叠、无覆盖/非法时间/planHash 变化拒绝。
2. 合成红、蓝、绿片段精准裁剪与拼接：5 秒、125 帧；逐帧时间戳、画面顺序、音频时长和有声/无声混合后的静音内容验证。
3. 兼容快速导出；音轨/编码参数不兼容失败，显式精准重试使用新 ID，保留失败历史。
4. 运行中取消；输入被改动后禁止重试，不静默更新旧计划。
5. 模拟发布重命名后、DB 提交前崩溃：未完成结果下载返回 409；新 Worker 第二次尝试对账复用，只有一个登记结果。
6. 真实长 GOP 合成样本：快速裁剪时长偏差超过 5 秒明确失败，没有发布文件；精准重试准确生成 25 帧无音轨结果。
7. 发布时取消不登记 Artifact；旧租约无法完成任务；恢复后的尝试正常发布。

同时验证下载 GET/HEAD、UTF-8 安全文件名、内容大小、Range 前缀/后缀、非法多范围 416、ETag 304、过期 410、新 ID 重新导出和持久化幂等别名。

## 真实录像结果

执行：

```bash
python3 deploy/smoke_exports.py --controls
```

脚本选择已索引真实文件，不修改录像；下载结果及 JSON 存在 `data/qa/d4-smoke`。

| 场景 | 实际结果 |
| --- | --- |
| 整段快速导出 | 计划 363.008 秒，实际 362.993 秒，偏差 -15 ms；保留 HEVC/Opus、3840×2160，129,500,448 bytes |
| 两片段精准拼接 | 两段各 5 秒；跳过 992 ms 无录像断档；实际 10.000 秒，250 帧、25 fps，H.264/AAC、3840×2160，10,388,371 bytes |
| 浏览器回看区间 | 选定 5 秒的源存在长关键帧间隔，快速模式报 FAST_BOUNDARY_UNSAFE；点击精准重试，实际 5 秒、125 帧，结果开放下载 |
| 浏览器片段库多选 | 两个完整片段，计划 650.112 秒，实际 650.256 秒；保留 HEVC/Opus，258,914,808 bytes；下载事件返回实际 MP4 文件 |
| 浏览器详情导出 | 计划 322.112 秒，实际 322.117 秒，保留原编码；任务中心显示实际时长、有效期和下载按钮 |
| 运行中取消与重试 | 20 秒精准导出进入实际转码后取消，无发布结果；新 ID 重试完成 20 秒、500 帧，旧任务保留 cancelled |
| 强制重启 | 10 秒精准导出转码中 SIGKILL Worker；runtime 退出、Docker 自动重启；同任务第 1 次 interrupted、第 2 次 completed，实际 10 秒、250 帧 |

重启测试首次遇到 API 瞬时断连，任务本身恢复成功；验证脚本已加入断连重试并完整重跑通过。真实试验还发现长关键帧间隔会使 5 秒快速裁剪扩展为数分钟，已增加逐片段 5 秒偏差保护，回归与 UI 精准重试均通过。
