# D5：设置、日志、维护与备份验证

日期：2026-10-13；版本 0.6.0；分支 `codex/phase-one-backend`。

## 环境与范围

- 独立容器 `clipline-phase-one-clipline-1`，8088，镜像 d5-local；旧 8083 服务未修改。
- `/Volumes/extended/clipline` → `/recordings` 只读；应用数据独立写入 `data/local-test`。
- 原有媒体 123 个 MP4、16,508,780,544 bytes。两个测试源引用同一批录像，界面总计不是原文件的额外复制。
- linux/arm64、linux/amd64 镜像构建；真实数据在 ARM64 容器验证。另在 amd64 仿真容器完成精准导出、到期清理和备份校验；原生双架构 NAS 发布验收仍在 D6。
- SQLite 从 0003 升至 0004，自动保存一致性备份和 schema/SHA256 manifest；保留日志 UUID、源、索引、任务和尝试历史。

## 自动验证

后端 Python 3.11/3.12 各 103 项测试通过；ruff lint/format 通过。前端 21 项测试、生产构建通过。D5 新增 13 项后端场景与 4 项前端状态场景：

- 分类保存、严格类型/字段白名单、只读分类与识别启用拒绝、revision 409、并发保存只有一个胜者。
- 新源默认频率、仅手动 null、近期文件保护快照、默认导出模式/跨度、任务并行领取动态生效且不打断已运行任务。
- 日志类型/级别/源/任务/中文关键词筛选；百分号作为文字，稳定序号快照跨页不混入新记录。
- 全量 JSON 导出、诊断白名单、结构化详情、HEAD 与失效快照；任意 secret/provider 字段不导出。
- SSE 事件重放、过期/超过当前最大游标 reset、日志/事件保留与维护状态。
- 下载租约过期后 OS 共享锁仍阻止删除；下载关闭后删除过期导出与 manifest，保留完成历史。
- 播放视图租约、LRU 跳过活跃结果；空间不足明确失败；关闭/过期租约后可释放。
- 活跃尝试保护，终态临时目录/孤立 manifest 清理；原录像、未知用户目录、符号链接及符号链接祖先不进入清理。
- 在线备份包含 WAL；manifest/schema 校验、API/Worker 活跃时拒绝恢复、离线恢复并保留恢复前 DB、旧 schema 升级/回滚演练。
- 前端分类序列化隔离、脏分类及其原版本保留、干净分类同步，以及过时 GET/保存回复不能覆盖更高版本。

## 真实数据验证

执行 `python3 deploy/smoke_operations.py`，结果 JSON 保存在忽略的 `data/qa/d5-smoke`。

| 场景 | 结果 |
| --- | --- |
| 分类保存与 SSE | tasks 分类保存生效，其他三分类相同；旧 revision 返回 409；SSE after 游标收到 SETTINGS_UPDATED |
| 真实下载保护 | 生成 129,413,060 bytes 的 HEVC/Opus MP4；下载暂停且人为让使用租约过期，维护仍保留文件（OS 锁保护） |
| 到期行为 | 人为推进本次测试 Artifact 的到期时间，新请求 410；已有下载继续，字节数与 SHA256 完全匹配 |
| 物理清理与重导出 | 下载结束后文件和 manifest 删除；旧 Task completed 且 downloadStatus=expired；新 ID 重导出成功，关联原任务 |
| 日志快照 | 服务端页只加载 2 条，导出包含关联任务全部 8 条；诊断含 schema/架构、配置摘要、任务和白名单日志 |
| 在线备份 | 当前库一致性备份并验证，schema 0004、大小 1,605,632 bytes（随后续运行可变化） |
| 源文件保护 | 123 个原文件的大小、mtime、首尾内容采样摘要前后相同；只读挂载验证通过 |
| 二期边界 | transcription / visualRecognition / semanticSearch 均 false，原有占位保留，无模型加载 |

测试配置恢复到运行前的值，未更改既有源频率。恢复演练只在临时数据库执行，没有把真实数据库回退。

## 浏览器检查

- 未保存扫描草稿时保存导出分类，扫描草稿仍保留；切换任务页后返回亦保留。
- 已保存的精准默认模式出现在新导出弹窗，取消预览不创建任务。
- 另一请求修改后台并行后，保存旧草稿显示冲突；核对后显式保存，随后恢复默认，保留期/路径/重型资源只读。
- 日志中心先加载 50 条，加载更多为 100 条；实际浏览器下载 JSON 含全部 950 条匹配记录，非当前页。
- 中文“下载保护”与导出类型筛选得到真实完成记录；结构化详情和任务/日志互跳正常。
- 日志列表显示可读业务摘要，完整字段在详情查看；保留蓝色主题及二期占位。
- 截图位于忽略的 `data/qa/d5-settings.jpg`、`data/qa/d5-logs.jpg`。私有媒体、设备目录名、数据库和详细诊断不提交仓库。
