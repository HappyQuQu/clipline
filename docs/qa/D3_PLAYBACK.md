## 已接通

默认页面使用真实 API：Logo 下的源选择、真实目录浏览/添加/编辑/启停/扫描、本地日期与 UniFi 竖向时间轴、原文件/兼容版本播放、时间定位与续播、右侧详情/窄屏抽屉、片段库分页和文件名/起止时间搜索、全局搜索跳转。扫描与播放准备的任务及关联日志也读取服务端。

后端增加日期、时间轴、resolve、playback、prepare 与 media 接口。覆盖取区间并集，重叠定位采用最早开始时间/ID 的稳定顺序；续播跳过已覆盖部分。时间轴返回整日覆盖与断档，文件详情按可视时间窗分页读取。

直接播放为 H.264/AAC 或无音轨 MP4/MOV；浏览器实际失败可请求兼容准备。HEVC/Opus 等输入在 Worker 中转 MP4/H.264/YUV420P，已有音轨转 AAC，无音轨不补音频；默认最大宽度 1920。profile 包含实现版本与部署宽度，任务去重、媒体槽、原始指纹和输出验证后发布，Range GET 不执行转码。

原型保留为显式 `?mode=demo`，真实模式不读取演示 localStorage，API 失败不静默回退。D4 导出按钮当前禁用，截取区间可编辑；D5 设置只读，日志导出/诊断禁用。七个二期代码插槽及六处静态占位保持，时间轴不显示识别占位；识别能力全部为 false。

## 指定目录实测

`/Volumes/extended/clipline:ro` → `/recordings`，新数据与输出独立位于 `data/local-test` → `/app/data`。media 下的 123 个真实 MP4，HEVC/Opus、3840×2160，包含 2026-06-01/02 两个日期；6 月 2 日有 71 个重叠当日的片段。为切源测试额外添加 media 父目录源，覆盖同一批只读文件；不会把重复索引计成新增原文件。

原生 ARM64 Docker 执行：

```bash
python3 deploy/smoke_playback.py --restart
```

验证后台准备复用、转码期间 SIGKILL Worker、进程组回收和容器重启；原任务 attemptNo=2、旧尝试 interrupted，恢复完成。生成的真实代理可读取 206 首段，越界返回 416，后续准备请求复用已完成缓存。示例恢复结果时长 318,929 ms、大小 97,290,786 字节，原始索引时长 318,854 ms；输出差异 75 ms。原始录像映射 RW=false。

浏览器人工操作验证：

- 创建真实 media 目录源，取消首次扫描选项后为空态；手动提交扫描后立即进入任务中心，稍后出现真实索引与日期。
- 在两个真实源之间切换，连续切换两个日期并快速返回相同日期；播放器及详情不串源。跨午夜片段从当日零点回看时媒体偏移为 1,080 秒，加载后 readyState=4，播放后 paused=false、currentTime 持续前进。
- 片段库按源/日期筛选，输入 `08：25：56` 得到真实文件；回看跳转定位到正确片段。无编码筛选，字幕/标签/识别状态保持二期占位。
- 1600 px 宽屏为右侧详情，390 px 为可关闭抽屉；展示真实时长、4K 分辨率、编码、大小、文件状态及跨日原始时间。
- 拖到片段结束，自动跳过断档并进入下一片段；后台准备后继续播放，详情同步更新。
- 截取起点修改为 08:32:00，自动续播进入新片段后仍保持 08:32:00–08:36:33。
- 从任务中心取消正在执行的真实转码，先显示取消中，实际进程退出后为已取消；关联日志包含取消请求和终态，未发布半成品。

真实画面、设备路径和详细运行数据仅保存于被忽略的本地 data 目录，不提交到公开仓库。浏览器最终截图也保存在 `data/qa/`。

最终镜像重新部署后，普通播放 smoke 复用真实缓存，日期/定位及 206/416 再次通过。amd64 镜像另在 ARM 主机的模拟环境中读取同一只读映射，发现 123 个录像并探测到 HEVC/Opus；临时目录中的合成媒体成功生成并探测 H.264/AAC。该项验证 x86 镜像工具可执行，不代表真实录像完整转码或原生 x86 NAS 验收。
